# Legend

Legend est un prototype de MMORPG tactique inspiré de Dofus, pensé pour le web.

## Vision

Créer un MMORPG accessible depuis le navigateur, avec :
- combats tactiques au tour par tour sur grille,
- progression de personnage,
- classes fortes et identifiables,
- contenu extensible vers multijoueur, inventaire, équipement et monde persistant.

## État actuel

Le dépôt contient un **prototype MVP jouable en un seul fichier HTML** :
- grille 8x8,
- combat 1v1,
- 3 classes de base,
- déplacement,
- sort principal,
- IA ennemie,
- HUD et log de combat.

## Objectif du prototype 1

Valider un noyau de combat tactique fun et lisible avec :
- une boucle de tour claire,
- du positionnement intéressant,
- des classes différenciées,
- une architecture simple mais extensible.

## Stack actuelle

- HTML
- CSS
- JavaScript natif
- Canvas 2D

## Philosophie technique

Pour l’instant :
- zéro framework,
- zéro dépendance externe,
- un prototype rapide et jouable,
- code organisé pour faciliter une future migration vers une architecture plus large.
